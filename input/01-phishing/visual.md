# Визуальное решение

## Опора

Посмотри input/01-phishing/references/approved-style.png. Это утверждённый рисунок сайта «ЗАВОД»: живая гуашь/цветной карандаш, ощутимая фактура, слегка неровный контур, характер. Референс определяет манеру, а не обязательный сюжет из четырёх людей.

Кадры видео в references показывают композицию и механику: нарисованный ноутбук, внутри письмо, поверх — всплывающая обратная связь. Не копируй чужие тексты, брендинг или персонажей из видео. Не повторяй обрезанный низ попапа в reference-feedback.png.

## Палитра интерфейса

| Назначение | Цвет |

| Почти белые кремовые поверхности | #FFFCF6 |
| Сливовый текст и основные контуры | #462638 |
| Второстепенный текст | #756571 |

| Тонкие границы | #DDCED2 |
| Hover синей кнопки | #254987 |
| Pressed синей кнопки | #1C3667 |

Принцип 70/20/10: преимущественно спокойный светлый фон, затем кремовые/сливовые элементы, небольшая доля синего акцента. Это ориентир композиции, не автоматический подсчёт пикселей. Иллюстрация может быть насыщеннее интерфейса. Не добавляй большие разноцветные плашки каждому агенту/ответу.

Ответы различаются не только цветом: иконка, подпись, видимая рамка. Ошибка — спокойная поясняющая подача без агрессивного красного экрана. Проверь контраст текста и фокуса.

## Типографика и рисунок

Заголовки Lora, основной текст Golos Text, короткие рукописные акценты Caveat. Внутри письма — читаемый основной шрифт. Рукописный только в подписи вне ноутбука, не в условиях и вариантах ответа.

Шрифты должны работать локально: включи доступные файлы с лицензиями или явно зафиксируй согласованную системную замену. Не полагайся на скрытую загрузку Google Fonts. Системная замена для технической пробы допустима, но не выдавай её за загруженный брендовый шрифт.

Нарисуй ноутбук с простым фронтальным экраном и небольшим количеством предметных деталей. Не добавляй вокруг героя-хакера, щиты, замки, гирлянды иконок. Основной герой сцены — письмо.

Короткие рукописные стрелки допустимы в инструкции, но не указывают заранее на правильные ответы. Интерфейс, текст и попапы — настоящие элементы HTML, не рисунок экрана.

## Микроанимации

Одно появление уведомления о письме, спокойное открытие попапа, короткое подтверждение действия. Без автозвука, бесконечной тряски и отсчёта, который мешает думать. Предпочтение reduced motion отключает необязательное движение.

Новая генерация: сначала один ноутбук и одна композиционная проба на согласование. После утверждения используй этот рисунок для обоих примеров.
