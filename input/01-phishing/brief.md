# Первый запуск: письмо под лупой



run_id: phishing-01



Создать одно интерактивное упражнение для взрослого сотрудника, который пользуется рабочей почтой. Участник анализирует письмо и обосновывает, какие фрагменты настораживают. Ориентир прохождения 3–5 минут, без жёсткого таймера.



## Что должно быть на экране



Получение письма на нарисованном ноутбуке; открытие письма; поиск фрагментов; выбор объяснения; всплывающая адресная обратная связь; итог и порядок безопасных действий. Рисунок — в стиле «ЗАВОДА», референсы уже в проекте.



Источник фактов — material.md. Четыре целевых признака и три нейтральных наблюдения. Не ставить заранее цифру «найдите 4». Выбор фрагментов должен требовать чтения письма, а объяснения — различения правдоподобных версий.



## Центральное требование автора



Неправильные объяснения не должны быть заведомо нелепыми. Нельзя сделать один содержательный правильный ответ рядом с двумя карикатурными. Методист обосновывает каждый дистрактор, контролёр проверяет неоднозначность до согласования.



## Результат



Отдельная переносимая папка HTML-упражнения. Не урок из множества экранов, не SCORM. Это демонстрация реальной работы завода: исходные правила → сценарий → согласование → визуал → согласование → сборка → контроль.



Перед первой сборкой сценарий и визуальный образец утверждает пользователь.
