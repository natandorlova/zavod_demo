# Материалы курса
01-phishing — комплект для первого упражнения: бриф, письмо, оформление, поведение, картинки и референсы. Для практики первого урока его не меняем.
Позже для новой темы создай рядом другую папку с такими же видами материалов и назови её в команде бригадиру. Утверждённые роли и скиллы можно использовать повторно.
