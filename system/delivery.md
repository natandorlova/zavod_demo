# Техническая передача

## Результат каждого запуска

output/<run_id>/
- index.html
- styles.css
- app.js
- exercise-data.js
- assets/laptop.webp, assets/office.webp и используемые локальные шрифты/лицензии
- README.md: как открыть, что проверено, ограничения

Работает локально без сети. Обычные подключаемые скрипты, без fetch для чтения JSON и без ES-module ограничений file://. Исходные данные хранятся в output/work/<run_id>/exercise-vN.json, затем переносятся в exercise-data.js как window.EXERCISE. В HTML не вставляй непроверенную разметку из данных: выводи строки безопасными DOM-операциями.

Раздели движок и данные, чтобы второй запуск не требовал переписывать всё. Не добавляй React, npm-сборку, API, библиотеку анимаций или сервер без конкретной необходимости. Локальный HTTP-сервер допустим как средство предпросмотра и проверки, привязка 127.0.0.1.

Не создавай SCORM, вход в систему, панель администратора, макеты лендинга, синтетические журналы «работы ИИ». Не публикуй проект автоматически.

## Проверяемые свойства

1. Целые ссылки на локальные ассеты, никаких файлов с чужими абсолютными путями.
2. Версии одобренных сценария и визуала записаны в assembly-notes.md.
3. Первый результат сохраняется при запуске второго.
4. Выполнена структурная проверка exercise JSON:
   python system/tools/check-exercise.py output/work/<run_id>/exercise-vN.json
5. Выполнена проверка браузера по навыку контролёра, а не только валидатором.
6. В папке нет секретов, реальных писем и контактов.
7. Если нужны внешние шрифты, предварительно проверь лицензию и доступность; не делай сетевую зависимость финального результата.

## Область правок

Методист: output/work/<run_id>/scenario-*, exercise-*, options-review-*.
Художник: output/work/<run_id>/visual-vN/.
Сборщик: output/<run_id>/ и output/work/<run_id>/assembly-notes.md; preview.html по запросу художника.
Контролёр: output/reports/<run_id>/.
Главный: state.json, log.md, сводки и назначения.

## Что означает «готово»

Согласованы сценарий и визуал; результат открывается; все объяснения и обратная связь доступны; основные ветки пройдены; размеры desktop проверены; нет blocker/major; известные ограничения названы. Скрипт проверки структуры не доказывает смысловую корректность и качество интерфейса.
