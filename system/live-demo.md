# Первый запуск на готовой иллюстрации

Использовать input/01-phishing/assets/laptop.webp и input/01-phishing/assets/office.webp. Это ранее подготовленные изображения для демо. Не выдавать их за результат текущего художника.

Художник открывает рисунок, измеряет прямоугольник экрана, оформляет layout.json и готовит preview.html с согласованным текстом и самым длинным попапом. Системные шрифты Arial и Georgia разрешены для этого учебного комплекта; локальное открытие без сети обязательно.

Согласование композиции остаётся обязательным. После запроса нового рисунка выполняется обычная генерация по roles/artist.md и input/01-phishing/visual.md. Если генерации нет, предложить готовые assets и назвать источник, а не заменять рисунок случайным изображением.

Все прежние указания «нарисуй новый ноутбук» относятся к режиму новой генерации. Режим первого запуска имеет приоритет при конфликте с ними.
